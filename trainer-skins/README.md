# Trainer skins

Player skins (64x64 PNG) for origins_trainers NPCs, loaded by URL from the trainer files
(`"skin": { "url": "https://raw.githubusercontent.com/backyarddd/origins-server-resourcepack/main/trainer-skins/<file>.png" }`).
Not part of the resource pack zip.

- `champion_cynthia.png`: Champion Cynthia (wide arms).
